# Forkit Changelog

## Version v0.1.0 - 11.06.2026
### Added.
- HTML support: efault html elements, text elements, lists, tables, form elements, default input(email, date, number) etc.
- Basic CSS support: Colors, texts, boxes etc.
- Basic JavaScript support: variables, operators and console.
- Browser tab system, multi tab.
- HTTP, HTTPS support.
- Character encoding support.
- Keyboard shortcuts.
