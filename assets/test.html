1. Stylesheet Cascade

This card gets its rounded corners, background, border and padding from a style block.

This paragraph is highlighted via a .highlight class rule.

This text uses rgba(0,0,0,0.45) semi-transparent black via the .muted rule.

2. Alpha-Channel Colors (rgba and hsla)

rgba(200,0,0,1.0) - fully opaque red

rgba(200,0,0,0.6) - 60 percent red

rgba(200,0,0,0.25) - 25 percent red (faded)

hsla(210,80%,55%,0.3) - translucent blue background

rgba(255,165,0,0.3) - light orange background

3. Border Radius

border-radius: 12px - uniform rounded box
border-radius: 4px 20px 4px 20px - alternating corners
border-radius: 999px - pill shape

4. CSS Math and Viewport Units

width: calc(100% - 40px)

font-size: clamp(14px, 2vw, 22px) - responsive font size

max-width: min(500px, 80vw)

padding-left: max(8px, 2vw)
