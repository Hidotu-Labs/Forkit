Hello from Forkit

This is a minimal HTML5 browser written in C using SDL2 and SDL2_ttf.

Features

  • HTML tokenizer and DOM builder
  • Inline CSS parser (color, font-size, background-color)
  • Block and inline layout
  • Text wrapping
  • Scroll with mouse wheel or arrow keys
